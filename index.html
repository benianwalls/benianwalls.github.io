Projects

MalwareScope

Python · PyTorch · scikit-learn · FastAPI · SHAP

ML-powered static malware detector for Windows PE files, training Random Forest and PyTorch neural-network models on the EMBER2018/2024 benchmarks; the best model detects 79% of malware at a deployable 0.1% false-positive rate. Added SHAP explainability, a calibrated UNCERTAIN band, and a VirusTotal cross-check, served through a FastAPI web dashboard, CLI, and a Chrome extension that scans downloads in real time.

LLM Agent Security Lab

Python · Git · GitHub

A vulnerable-and-defended LLM-agent environment to evaluate indirect prompt injection, mock data exfiltration, system prompt leakage, and unsafe tool execution in a controlled sandbox. Implemented model-independent guardrails, including least-privilege tool access, output encoding, and recipient restrictions.
